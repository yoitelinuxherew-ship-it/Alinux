The **Search Characters** endpoint allows you to find characters by name using partial or full string matching. Results are drawn from both anime and manga titles in the Koax database, making it ideal for powering autocomplete fields, character lookup features, or fan exploration tools. The query is matched against both the romanized name and the original Japanese name.

## Endpoint

```
GET https://api.koax.dev/v1/characters/search
```

## Query Parameters

<ParamField query="q" type="string" required>
  The search term to match against character names. Supports partial matching — for example, `sakura` will match `Sakura Haruno`, `Sakura Kinomoto`, and others. Minimum 2 characters required.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number of the result set to return.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Number of results to return per page. Maximum allowed value is **50**.
</ParamField>

<ParamField query="order_by" type="string">
  Field to sort results by. Accepted values:

  - `name` — Sort alphabetically by character name
  - `favorites` — Sort by total number of user favorites
</ParamField>

<ParamField query="sort" type="string">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

## Example Request

```
GET https://api.koax.dev/v1/characters/search?q=sakura
```

## Examples

<Tip>
  For more precise results, try searching using the Japanese **kanji or kana** form of a character's name. For example, querying `q=春野サクラ` will return exact matches for Sakura Haruno without surfacing unrelated characters who share a romanized name. This is especially useful when disambiguating characters from different series with similar English spellings.
</Tip>
