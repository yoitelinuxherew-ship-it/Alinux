The **Get Character** endpoint returns the complete profile for a single anime or manga character, identified by their unique ID. The response includes a detailed biography, every anime and manga title the character appears in alongside their role, and a full list of voice actors across all dubbed and subbed language releases.

## Endpoint

```
GET https://api.koax.dev/v1/characters/:id
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique numeric identifier of the character. You can obtain character IDs from the [List Characters](/api-reference/characters/list) or [Search Characters](/api-reference/characters/search) endpoints.
</ParamField>

## Response Fields

<ResponseField name="id" type="integer">
  Unique identifier for the character.
</ResponseField>

<ResponseField name="name" type="string">
  The character's full name in romanized form (e.g., `"Naruto Uzumaki"`).
</ResponseField>

<ResponseField name="name_kanji" type="string">
  The character's name in Japanese kanji or kana script. Returns `null` for non-Japanese productions.
</ResponseField>

<ResponseField name="about" type="string">
  A detailed biography of the character, covering their background, personality, and role in the story. May include spoilers. Returns `null` if no biography is available.
</ResponseField>

<ResponseField name="image_url" type="string">
  URL of the character's primary portrait image hosted on the Koax CDN.
</ResponseField>

<ResponseField name="favorites" type="integer">
  Total number of users who have marked this character as a favorite.
</ResponseField>

<ResponseField name="anime" type="array">
  List of anime titles in which this character appears.

  <Expandable title="Anime appearance object">
    <ResponseField name="id" type="integer">
      Unique ID of the anime title.
    </ResponseField>
    <ResponseField name="title" type="string">
      The anime title in its original romanized form.
    </ResponseField>
    <ResponseField name="image_url" type="string">
      Cover image URL for the anime title.
    </ResponseField>
    <ResponseField name="role" type="string">
      The character's role in this title. Either `"Main"` or `"Supporting"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="manga" type="array">
  List of manga titles in which this character appears.

  <Expandable title="Manga appearance object">
    <ResponseField name="id" type="integer">
      Unique ID of the manga title.
    </ResponseField>
    <ResponseField name="title" type="string">
      The manga title in its original romanized form.
    </ResponseField>
    <ResponseField name="image_url" type="string">
      Cover image URL for the manga title.
    </ResponseField>
    <ResponseField name="role" type="string">
      The character's role in this title. Either `"Main"` or `"Supporting"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="voice_actors" type="array">
  List of voice actors who have portrayed this character, grouped by language.

  <Expandable title="Voice actor object">
    <ResponseField name="name" type="string">
      Full name of the voice actor.
    </ResponseField>
    <ResponseField name="language" type="string">
      Language of the performance (e.g., `"Japanese"`, `"English"`, `"Spanish"`).
    </ResponseField>
    <ResponseField name="image_url" type="string">
      Photo URL of the voice actor.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  The `role` field indicates whether a character is a **Main** protagonist/antagonist central to the story, or a **Supporting** character with a more limited narrative role. This distinction is title-specific — a character may be `Main` in one series and `Supporting` in a spin-off or crossover.
</Note>
