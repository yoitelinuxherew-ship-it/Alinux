The `/anime/top` endpoint returns an ordered list of the highest-rated anime in the Koax database, ranked by their weighted community score by default. You can switch the ranking metric to popularity (list additions), favourites (explicit saves), airing status, or upcoming releases using the `filter` parameter — making this endpoint equally useful for "trending now" widgets, genre leaderboards, and personalised recommendation carousels.

## Endpoint

```
GET https://api.koax.dev/v1/anime/top
```

## Query Parameters

<ParamField query="type" type="string">
  Restrict the top list to a specific anime format. One of `TV`, `Movie`, `OVA`, `ONA`, or `Special`.
</ParamField>

<ParamField query="limit" type="integer" default={25}>
  Number of results to return. Maximum is `50`.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  Page number to retrieve, enabling you to paginate through extended rankings (e.g. positions 26–50).
</ParamField>

<ParamField query="filter" type="string">
  Change the ranking metric used to build the list. When omitted, results are ranked by **score**.

  | Value          | Ranks by                                                      |
  |----------------|---------------------------------------------------------------|
  | `airing`       | Score among currently-airing series only                      |
  | `upcoming`     | Anticipated titles not yet aired, ranked by list additions    |
  | `bypopularity` | Total number of users who added the title to any list         |
  | `favorite`     | Number of users who explicitly marked the title as a favourite |
</ParamField>

## Ranking Modes Explained

Koax supports four distinct ways to rank anime, each answering a different question:

- **Score** *(default)*: The classic leaderboard — weighted average of all community ratings on a 1–10 scale. Bayesian weighting prevents titles with very few votes from dominating. Best for surfacing objectively well-regarded series.
- **By Popularity** (`bypopularity`): Counts how many users have added a title to *any* list (watching, completed, plan-to-watch, etc.). High-popularity titles are widely known but not necessarily top-rated — ideal for mainstream recommendation features.
- **Favourite** (`favorite`): Counts deliberate "favourite" saves — a stronger signal of genuine love for a series than a passive list add. Useful for surfaces like "most beloved of all time."
- **Airing / Upcoming** (`airing`, `upcoming`): Scoped leaderboards for currently-broadcasting series and announced-but-not-yet-aired titles. Perfect for a "what's hot this season" widget.

## Response

Each entry in the `data` array includes a `rank` field reflecting its position in the requested ranking mode, alongside core anime metadata.

<ResponseField name="filter" type="string">
  The ranking mode applied to this response. Reflects the `filter` query parameter, defaulting to `"score"` when omitted.
</ResponseField>

<ResponseField name="data" type="array">
  An ordered array of ranked Anime Objects.

  <Expandable title="Ranked Anime Object">
    <ResponseField name="rank" type="integer">
      Position in the global ranking for the selected `filter` mode.
    </ResponseField>
    <ResponseField name="id" type="integer">
      Unique numeric identifier for the anime.
    </ResponseField>
    <ResponseField name="title" type="string">
      Primary romanised title.
    </ResponseField>
    <ResponseField name="title_english" type="string">
      Official English title, if available.
    </ResponseField>
    <ResponseField name="title_japanese" type="string">
      Native Japanese title in kanji/kana.
    </ResponseField>
    <ResponseField name="type" type="string">
      Anime format: `TV`, `Movie`, `OVA`, `ONA`, or `Special`.
    </ResponseField>
    <ResponseField name="episodes" type="integer">
      Total episode count. `null` if unknown or currently airing.
    </ResponseField>
    <ResponseField name="status" type="string">
      Airing status: `airing`, `finished`, or `upcoming`.
    </ResponseField>
    <ResponseField name="score" type="number">
      Community score on a scale of `1.00`–`10.00`.
    </ResponseField>
    <ResponseField name="popularity" type="integer">
      Popularity rank based on the number of users who have added the anime to their list.
    </ResponseField>
    <ResponseField name="image_url" type="string">
      URL to the anime's cover image.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata for the result set.

  <Expandable title="Pagination Object">
    <ResponseField name="current_page" type="integer">
      The page number returned.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      Number of items per page as requested.
    </ResponseField>
    <ResponseField name="total_items" type="integer">
      Total number of anime in the database for the applied ranking and type filter.
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      Total number of pages available.
    </ResponseField>
    <ResponseField name="has_next_page" type="boolean">
      `true` if a subsequent page exists.
    </ResponseField>
  </Expandable>
</ResponseField>

## Code Examples

<CodeGroup>

```bash curl
# Top 10 highest-rated anime overall
curl --request GET \
  --url "https://api.koax.dev/v1/anime/top?limit=10" \
  --header "Authorization: Bearer YOUR_API_KEY"

# Top 10 most popular currently-airing series
curl --request GET \
  --url "https://api.koax.dev/v1/anime/top?filter=airing&limit=10" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
// Top 10 most-favourited anime
const response = await fetch(
  "https://api.koax.dev/v1/anime/top?filter=favorite&limit=10",
  {
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  }
);

const { data } = await response.json();
data.forEach(({ rank, title_english, score }) => {
  console.log(`#${rank} ${title_english} — ${score}`);
});
```

```python Python
import requests

# Top 25 TV anime ranked by score
response = requests.get(
    "https://api.koax.dev/v1/anime/top",
    params={"type": "TV", "limit": 25},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)

for anime in response.json()["data"]:
    print(f"#{anime['rank']} {anime['title_english']} ({anime['score']})")
```

</CodeGroup>

<Tip>
  Combine `type=Movie` with the default score ranking to get an instant leaderboard of the greatest anime films of all time — perfect for a dedicated movie spotlight section in your app:

  ```
  GET https://api.koax.dev/v1/anime/top?type=Movie&limit=10
  ```

  Similarly, `type=Movie&filter=favorite` surfaces the most beloved films by explicit user preference, which can differ significantly from the score-based list.
</Tip>

<Note>
  Rank positions reflect the **global** ordering across all entries in the database; they are not re-indexed after applying a `type` filter. This means you may see non-consecutive rank numbers (e.g. `#2`, `#5`, `#11`) when filtering by type, because the gaps are occupied by anime of other types.
</Note>
