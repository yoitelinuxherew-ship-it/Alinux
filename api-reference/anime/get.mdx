The `/anime/:id` endpoint returns the complete record for a single anime entry. This includes all metadata fields — episode count, scores, rankings, a full synopsis, genre and studio associations, broadcast dates, and links to cover art and trailers. Use this endpoint when you need to render a detail view or enrich a previously listed item.

## Endpoint

```
GET https://api.koax.dev/v1/anime/:id
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique numeric ID of the anime. You can obtain IDs from the [List Anime](/api-reference/anime/list) or [Search Anime](/api-reference/anime/search) endpoints.
</ParamField>

## Response Fields

<ResponseField name="id" type="integer">
  Unique numeric identifier for the anime.
</ResponseField>

<ResponseField name="title" type="string">
  Primary romanised title (e.g. `"Shingeki no Kyojin"`).
</ResponseField>

<ResponseField name="title_english" type="string">
  Official English localisation of the title. May be `null` if no official translation exists.
</ResponseField>

<ResponseField name="title_japanese" type="string">
  Native Japanese title in kanji/kana (e.g. `"進撃の巨人"`).
</ResponseField>

<ResponseField name="type" type="string">
  Anime format. One of `TV`, `Movie`, `OVA`, `ONA`, or `Special`.
</ResponseField>

<ResponseField name="episodes" type="integer">
  Total number of episodes. Returns `null` for currently-airing series where the count is not yet confirmed.
</ResponseField>

<ResponseField name="status" type="string">
  Current airing status: `airing`, `finished`, or `upcoming`.
</ResponseField>

<ResponseField name="score" type="number">
  Weighted community score on a scale of `1.00`–`10.00`.
</ResponseField>

<ResponseField name="rank" type="integer">
  Global rank by score among all anime in the database.
</ResponseField>

<ResponseField name="popularity" type="integer">
  Popularity rank based on the number of users who have added the anime to their list.
</ResponseField>

<ResponseField name="synopsis" type="string">
  Full plot summary of the anime.
</ResponseField>

<ResponseField name="genres" type="array">
  List of genre objects associated with this anime.

  <Expandable title="Genre Object">
    <ResponseField name="id" type="integer">
      Unique genre ID.
    </ResponseField>
    <ResponseField name="name" type="string">
      Genre name (e.g. `"Action"`, `"Drama"`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="studios" type="array">
  List of studio objects that produced this anime.

  <Expandable title="Studio Object">
    <ResponseField name="id" type="integer">
      Unique studio ID.
    </ResponseField>
    <ResponseField name="name" type="string">
      Studio name (e.g. `"Wit Studio"`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="aired" type="object">
  Broadcast window for the anime.

  <Expandable title="Aired Object">
    <ResponseField name="from" type="string">
      ISO 8601 date of the first episode broadcast.
    </ResponseField>
    <ResponseField name="to" type="string">
      ISO 8601 date of the final episode broadcast. `null` if the series is still airing.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="image_url" type="string">
  Absolute URL to the anime's cover image (JPEG, typically 225×318 px).
</ResponseField>

<ResponseField name="trailer_url" type="string">
  URL to the official trailer (usually a YouTube link). `null` if unavailable.
</ResponseField>

## Example Request

```bash curl
curl --request GET \
  --url "https://api.koax.dev/v1/anime/16498" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Code Examples

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.koax.dev/v1/anime/16498" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const animeId = 16498;

const response = await fetch(`https://api.koax.dev/v1/anime/${animeId}`, {
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
  },
});

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`);
}

const anime = await response.json();
console.log(anime.title_english); // "Attack on Titan"
```

```python Python
import requests

anime_id = 16498

response = requests.get(
    f"https://api.koax.dev/v1/anime/{anime_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)

if response.status_code == 404:
    print("Anime not found")
else:
    anime = response.json()
    print(anime["title_english"])  # "Attack on Titan"
```

</CodeGroup>

<Warning>
  If the provided `id` does not match any anime in the database, the API returns a **404 Not Found** response:

  ```json
  {
    "error": {
      "code": "ANIME_NOT_FOUND",
      "message": "No anime found with ID 99999."
    }
  }
  ```

  Always handle `404` responses in your client to surface a user-friendly message rather than exposing a raw error.
</Warning>

<Note>
  IDs are stable and will not change over time. You can safely cache an anime ID alongside your own data and use it for future lookups.
</Note>
