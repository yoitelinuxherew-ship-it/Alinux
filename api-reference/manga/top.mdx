---
title: "GET /manga/top — Top-Rated Manga"
sidebarTitle: "Top Manga"
description: "GET /manga/top — Retrieve the highest-rated manga ranked by community score, filterable by type and ranking category."
---

The `/manga/top` endpoint returns manga ordered by descending community score, giving you a ranked list of the most acclaimed titles in the database. An optional `filter` parameter lets you scope the ranking to a specific format — such as novels, manhwa, or manhua — or switch to an alternative ranking method like popularity or all-time favorites. Use this endpoint to power leaderboards, featured carousels, or genre-specific top lists.

## Endpoint

```
GET https://api.koax.dev/v1/manga/top
```

## Query Parameters

<ParamField query="filter" type="string">
  Narrows the ranking to a specific publication type or ranking methodology. Accepted values:

  | Value | Description |
  |-------|-------------|
  | `manga` | Standard Japanese manga only |
  | `novels` | Light novels and prose novels |
  | `manhwa` | Korean comics only |
  | `manhua` | Chinese comics only |
  | `bypopularity` | Ranked by number of user list entries instead of score |
  | `favorite` | Ranked by the number of times added to favorites |

  When omitted, all publication types are included and ranked by score.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Number of results to return per page. Maximum value is `50`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number to retrieve, for paginating through the full ranked list.
</ParamField>

<ParamField query="type" type="string">
  Alternative way to filter by publication type. Accepted values: `Manga`, `Novel`, `One-shot`, `Doujin`, `Manhwa`, `Manhua`. Overlaps with the `filter` parameter — if both are provided, `filter` takes precedence for type-based filtering.
</ParamField>

<Tip>
  Use `filter=novels` to retrieve a top chart scoped exclusively to light novels and prose novels. This is useful for dedicated novel-reading apps or sections where mixing manga and novel rankings would be confusing for users.
</Tip>

## Example

<CodeGroup>

```bash cURL
curl -X GET "https://api.koax.dev/v1/manga/top?limit=3&page=1" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
