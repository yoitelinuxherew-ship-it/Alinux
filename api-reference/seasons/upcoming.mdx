---

The **Upcoming Season** endpoint returns all anime titles announced for the next broadcast season. Entries are populated as studios and licensors release official announcements, so the list grows progressively as the season approaches. Each entry includes confirmed premiere dates, episode counts where available, and studio information — giving you everything needed to help users discover and plan for what's coming next.

## Endpoint

```
GET https://api.koax.dev/v1/seasons/upcoming
```

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number of the result set to return.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Number of anime to return per page. Maximum allowed value is **50**.
</ParamField>

<ParamField query="order_by" type="string">
  Field to sort results by. Accepted values:

  - `title` — Sort alphabetically
  - `popularity` — Sort by number of users who have added the title to their watchlist
</ParamField>

<ParamField query="sort" type="string">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

<ParamField query="filter" type="string">
  Filter by anime format. Accepted values: `tv`, `movie`, `ova`, `ona`, `special`.
</ParamField>

## Examples

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.koax.dev/v1/seasons/upcoming?filter=tv&order_by=popularity&sort=desc" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Tip>
  The upcoming season endpoint is a great foundation for **watchlist and countdown features**. Since `premiere_date` is included for each confirmed title, you can calculate days-until-premiere client-side and surface a countdown timer in your UI. Pair this with the `popularity_rank` field to highlight the most-anticipated titles first — perfect for a "Coming Soon" hero section or pre-season hype feed.
</Tip>
