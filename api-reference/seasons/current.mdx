The **Current Season** endpoint returns all anime titles airing during the current broadcast season. Seasons are determined automatically by the current calendar date and follow the standard Japanese broadcast calendar: Winter, Spring, Summer, and Fall. This endpoint is ideal for building "Airing Now" dashboards, season overview pages, or real-time popularity rankings.

## Endpoint

```
GET https://api.koax.dev/v1/seasons/current
```

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number of the result set to return.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Number of anime to return per page. Maximum allowed value is **50**.
</ParamField>

<ParamField query="order_by" type="string">
  Field to sort results by. Accepted values:

  - `score` — Sort by current average community score
  - `popularity` — Sort by number of users tracking the title
  - `title` — Sort alphabetically
</ParamField>

<ParamField query="sort" type="string">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

<ParamField query="filter" type="string">
  Filter results to a specific anime format. Accepted values:

  - `tv` — Regular TV broadcast series
  - `movie` — Theatrical films
  - `ova` — Original Video Animation
  - `ona` — Original Net Animation (streaming-first)
  - `special` — Special episodes or shorts
</ParamField>

## Examples

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.koax.dev/v1/seasons/current?order_by=score&sort=desc&filter=tv" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  The current season is determined by the calendar date of your request, using the following boundaries:

  | Season | Months       |
  |--------|--------------|
  | Winter | January – March |
  | Spring | April – June |
  | Summer | July – September |
  | Fall   | October – December |

  Season boundaries are based on UTC time. If your application is timezone-sensitive, consider confirming the `season` and `year` fields from the response rather than inferring them client-side.
</Note>
