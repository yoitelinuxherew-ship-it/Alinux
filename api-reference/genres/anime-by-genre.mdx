The **Anime by Genre** endpoint returns a paginated list of all anime titles associated with a specific genre. This is the recommended way to build genre-browsing experiences, top-charts by category, or filtered recommendation feeds. Pass the genre `id` obtained from the [List Genres](/api-reference/genres/list) endpoint as a path parameter to get started.

## Endpoint

```
GET https://api.koax.dev/v1/genres/:id/anime
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique numeric ID of the genre. Retrieve available genre IDs from the [GET /genres](/api-reference/genres/list) endpoint.
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number of the result set to return.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Number of anime titles to return per page. Maximum allowed value is **50**.
</ParamField>

<ParamField query="order_by" type="string">
  Field to sort results by. Accepted values:

  - `score` — Sort by average community score
  - `title` — Sort alphabetically by title
  - `aired` — Sort by original air date
</ParamField>

<ParamField query="sort" type="string">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

## Examples

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.koax.dev/v1/genres/1/anime?order_by=score&sort=desc&limit=25" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Tip>
  Chain `order_by=score&sort=desc` to instantly surface the highest-rated titles in any genre — perfect for "Best of Genre" leaderboards or recommendation carousels. For example:

  ```
  GET https://api.koax.dev/v1/genres/1/anime?order_by=score&sort=desc
  ```

  Swap genre ID `1` (Action) for any ID from [GET /genres](/api-reference/genres/list) to replicate the pattern across every category.
</Tip>
