The **List Genres** endpoint returns all genre categories available in the Koax database. Each genre carries a unique numeric ID that you can pass as a filter parameter to other endpoints — such as anime or manga listings — to narrow results to a specific category. Use the `type` parameter to retrieve genres scoped to anime or manga, as the available genre sets differ between the two media types.

## Endpoint

```
GET https://api.koax.dev/v1/genres
```

## Query Parameters

<ParamField query="type" type="string" default="anime">
  Specifies the media type for which genres should be returned. Accepted values:

  - `anime` — Return genres applicable to anime titles
  - `manga` — Return genres applicable to manga titles
</ParamField>

## Response Fields

<ResponseField name="data" type="array">
  An array of Genre objects.

  <Expandable title="Genre object">
    <ResponseField name="id" type="integer">
      Unique numeric identifier for the genre. Use this value as `genre_id` in other endpoints.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the genre (e.g., `"Action"`, `"Romance"`).
    </ResponseField>
    <ResponseField name="description" type="string">
      A brief description of what titles in this genre typically involve.
    </ResponseField>
    <ResponseField name="count" type="integer">
      The total number of titles in the database tagged with this genre.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  To filter anime or manga results by genre, pass the genre's `id` as the `genre_id` query parameter on supported endpoints. For example, to list all action anime use:

  ```
  GET https://api.koax.dev/v1/anime?genre_id=1
  ```

  Or use the dedicated [Anime by Genre](/api-reference/genres/anime-by-genre) endpoint for paginated, sortable genre browsing.
</Note>
