Koax Anime API is a RESTful service that puts the full breadth of anime culture at your fingertips. Whether you're building a recommendation engine, a fan site, a mobile companion app, or an automated watchlist tracker, Koax gives you structured, up-to-date data on thousands of anime titles, manga series, beloved characters, genres, and seasonal release schedules — all through clean, predictable HTTP endpoints.

## What You Can Do

With Koax Anime API you can:

- **Search anime titles** by name, genre, release year, studio, or score range
- **Browse manga series** including volumes, chapters, authors, and serialization status
- **Retrieve character profiles** with descriptions, voice actors, and appearances across multiple series
- **Explore seasonal anime** to see what's airing in any given season and year
- **Filter by genre** to find action, romance, horror, isekai, or any of dozens of other categories
- **Fetch top-ranked and trending titles** using pre-built leaderboard endpoints
- **Get detailed episode information** including air dates, filler flags, and synopses
- **Look up studios and producers** along with their full catalogues of work

<Note>
  The free tier includes **1,000 requests per day**. This is enough to prototype, build hobby projects, and explore the full API surface. When you're ready to scale, check out the [pricing page](https://koax.dev/pricing) for higher-volume plans.
</Note>

## Base URL

Every request you make to the Koax Anime API must be directed to the following base URL. All endpoints documented in this reference are relative to this root.

```
https://api.koax.dev/v1
```

For example, to reach the top anime endpoint you would call:

```
https://api.koax.dev/v1/anime/top
```
