Characters are at the heart of every great anime, and the Koax Anime API gives you deep access to character data — from role classifications and detailed biographies to full voice actor rosters across every language dub. You can retrieve the full character catalog, look up individual character profiles, and search for characters by name, making it easy to build character browsers, fan trivia apps, and cast pages.

## List All Characters

To retrieve a paginated list of characters across the entire catalog, send a `GET` request to `/characters`. Use the `page` and `per_page` query parameters to walk through large result sets.

```bash
curl -X GET "https://api.koax.dev/v1/characters" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Each character object in the response includes the character's name, image, and a `voice_actors` array containing every voice actor who has played that character across different language productions.

## Get a Single Character

To retrieve the full profile for a specific character, use `GET /characters/{id}`. This returns a richer object than the list endpoint, including a detailed `about` biography, all anime and manga appearances, and the complete voice actor roster.

```bash
curl -X GET "https://api.koax.dev/v1/characters/17" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Sample response:**

```json
{
  "data": {
    "id": 17,
    "name": "Uzumaki, Naruto",
    "name_kanji": "うずまきナルト",
    "about": "Naruto Uzumaki is a shinobi of Konohagakure and the main protagonist of the series. Born on October 10th, he is the son of the Fourth Hokage and Kushina Uzumaki...",
```

<Accordion title="Character profile fields reference">

| Field          | Type     | Description                                           |
| -------------- | -------- | ----------------------------------------------------- |
| `id`           | integer  | Unique character identifier                          |
| `name`         | string   | Name in `Last, First` format                         |
| `name_kanji`   | string   | Original Japanese name (if available)                |
| `about`        | string   | Biography / description of the character             |
| `image_url`    | string   | URL of the character's portrait image                |
| `favorites`    | integer  | Number of users who have favorited this character    |
| `appearances`  | object   | Lists of anime and manga this character appears in   |
| `voice_actors` | array    | All voice actors across languages — see below        |

</Accordion>

## Search Characters by Name

The `/characters/search` endpoint lets you find characters directly by name. This is useful when users search your app for a specific character without knowing which anime they belong to.

```bash
curl -X GET "https://api.koax.dev/v1/characters/search?q=naruto" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The search supports partial name matching — querying `zoro` returns *Roronoa Zoro*, *Kuina*, and other partial matches. Results are ordered by community favorites count by default.

## Voice Actor Data

Every character object — whether returned from the characters list or the single character endpoint — includes a `voice_actors` array. Each entry in that array represents one voice actor who has played that character in a specific language production.

**Voice actor object fields:**

| Field       | Type   | Description                                          |
| ----------- | ------ | ---------------------------------------------------- |
| `name`      | string | Voice actor's name in `Last, First` format           |
| `language`  | string | Language of the dub (e.g., `Japanese`, `English`)    |
| `image_url` | string | URL of the voice actor's photo                       |

You can use this data to power features like "Find all anime with the same Japanese voice actor" or to display cast cards grouped by language in your UI.

## Building a Character Browser

The example below shows a complete workflow: search for characters by name, look up the first result's full profile, and render the cast details in the console. You can adapt this logic for any frontend framework.

```javascript
const BASE_URL = "https://api.koax.dev/v1";
const API_KEY = "YOUR_API_KEY";

async function apiFetch(path) {
  const response = await fetch(`${BASE_URL}${path}`, {
    headers: { Authorization: `Bearer ${API_KEY}` },
  });

  if (!response.ok) {
    throw new Error(`API error: ${response.status} ${response.statusText}`);
  }

  return response.json();
}

async function buildCharacterBrowser(searchQuery) {
  // Step 1: Search for characters by name
  const searchResults = await apiFetch(
    `/characters/search?q=${encodeURIComponent(searchQuery)}`
  );

  if (!searchResults.data.length) {
    console.log("No characters found.");
    return;
  }

  const topMatch = searchResults.data[0];
  console.log(`Top match: ${topMatch.name} (ID: ${topMatch.id})\n`);

  // Step 2: Fetch the full character profile
  const { data: character } = await apiFetch(`/characters/${topMatch.id}`);

  console.log(`🎭 ${character.name}`);
  console.log(`Favorites: ${character.favorites}`);
  console.log(`\nAppearances:`);
  character.appearances.anime.forEach((a) =>
    console.log(`  Anime — ${a.title} (${a.role})`)
  );
  character.appearances.manga.forEach((m) =>
    console.log(`  Manga — ${m.title} (${m.role})`)
  );

  // Step 3: Display voice actors grouped by language
  console.log(`\nVoice Actors:`);
  character.voice_actors.forEach((va) => {
    console.log(`  [${va.language}] ${va.name}`);
  });
}

buildCharacterBrowser("naruto").catch(console.error);
```

<Tip>
  Character data is a goldmine for fan-facing features. Consider using it to build **anime trivia quizzes** (show a character image, ask users to name the series), **voice actor spotlight pages** (list all roles for a single VA), or **character comparison tools** that let fans pit their favorite characters side by side. The `favorites` count on character profiles is a good proxy for popularity when ranking results.
</Tip>
