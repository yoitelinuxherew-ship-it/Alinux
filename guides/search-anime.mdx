The Koax Anime API gives you powerful search and filtering tools to help your users discover exactly the anime they're looking for. Whether you're building a recommendation engine, a seasonal chart, or a full-featured catalog browser, the search endpoints let you query by title, genre, release year, type, status, and more — and combine those filters freely to narrow down results with precision.

## Basic Title Search

To search for anime by title, send a `GET` request to `/anime/search` with the `q` query parameter. The API performs partial title matching, so you don't need to supply the exact title — `naruto` will match *Naruto*, *Naruto Shippuden*, *Boruto: Naruto Next Generations*, and more.

<CodeGroup>

```bash curl
curl -X GET "https://api.koax.dev/v1/anime/search?q=naruto" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  "https://api.koax.dev/v1/anime/search?q=naruto",
  {
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

<Tip>
  Always URL-encode your search terms before passing them as query parameters. Spaces should become `+` or `%20`, and special characters like `&`, `#`, or `:` must be percent-encoded. In JavaScript, use `encodeURIComponent(query)` to handle this automatically.
</Tip>

<Note>
  The search endpoint uses **partial (fuzzy) title matching** — you don't need to supply the full or exact title. Searching for `attack` will return *Attack on Titan*, *Attack on Titan: Junior High*, and other partial matches. If you need stricter matching, filter your results client-side after receiving the response.
</Note>

## Filter by Type

Use the `type` parameter to restrict results to a specific anime format. The supported values are:

| Value     | Description                              |
| --------- | ---------------------------------------- |
| `TV`      | Standard serialized television series   |
| `Movie`   | Theatrical or standalone film releases  |
| `OVA`     | Original Video Animation releases       |
| `ONA`     | Original Net Animation (streaming-first)|
| `Special` | Short specials and bonus episodes       |

```bash
curl -X GET "https://api.koax.dev/v1/anime/search?q=sword+art&type=TV" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Filter by Status

The `status` parameter lets you surface anime based on where it is in its run. This is especially useful for building "currently airing" feeds or "upcoming season" previews.

| Value      | Description                              |
| ---------- | ---------------------------------------- |
| `airing`   | Currently broadcasting new episodes     |
| `finished` | Completed run, all episodes released    |
| `upcoming` | Announced but not yet airing            |

```bash
curl -X GET "https://api.koax.dev/v1/anime/search?status=airing" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Filter by Genre

Pass a `genre_id` integer to filter results to a specific genre. You can retrieve a full list of genre IDs from the `/genres` endpoint, but some common ones are listed below:

| Genre ID | Genre Name    |
| -------- | ------------- |
| `1`      | Action        |
| `2`      | Adventure     |
| `4`      | Comedy        |
| `8`      | Drama         |
| `10`     | Fantasy       |
| `22`     | Romance       |
| `24`     | Sci-Fi        |
| `36`     | Slice of Life |

You can combine `genre_id` with a title search to narrow results further:

```bash
curl -X GET "https://api.koax.dev/v1/anime/search?q=hero&genre_id=1" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Filter by Year

The `year` parameter filters anime by the calendar year they first aired. This is ideal for building seasonal charts or "best of year" lists.

```bash
curl -X GET "https://api.koax.dev/v1/anime/search?year=2024" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Sort Results

Control the ordering of your results using `order_by` and `sort`. By default, results are sorted by relevance to your query.

| Parameter  | Description                        |
| ---------- | ---------------------------------- |
| `order_by` | Field to sort by                   |
| `sort`     | Direction: `asc` or `desc`         |

**Sortable fields for `order_by`:**

- `score` — Average community score
- `title` — Alphabetical by title
- `episodes` — Number of episodes
- `aired` — Air date (from)

```bash
# Get top-rated anime sorted by score, highest first
curl -X GET "https://api.koax.dev/v1/anime/search?order_by=score&sort=desc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Combining Filters

All filter parameters are combinable — the API applies them using AND logic, so every result satisfies every condition you specify. The example below finds currently airing TV anime from 2024, sorted by community score from highest to lowest.

<CodeGroup>

```bash curl
curl -X GET "https://api.koax.dev/v1/anime/search?status=airing&type=TV&year=2024&order_by=score&sort=desc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript (fetch)
const params = new URLSearchParams({
  status: "airing",
  type: "TV",
  year: "2024",
  order_by: "score",
  sort: "desc",
});

const response = await fetch(
  `https://api.koax.dev/v1/anime/search?${params}`,
  {
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  }
);

const { data, pagination } = await response.json();

data.forEach((anime) => {
  console.log(`${anime.title} — Score: ${anime.score}`);
});
```

```python Python
import requests

params = {
    "status": "airing",
    "type": "TV",
    "year": 2024,
    "order_by": "score",
    "sort": "desc",
}

response = requests.get(
    "https://api.koax.dev/v1/anime/search",
    params=params,
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)

data = response.json()

for anime in data["data"]:
    print(f"{anime['title']} — Score: {anime['score']}")
```
